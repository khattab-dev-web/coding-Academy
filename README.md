# Khattab.Dev

A modern online learning platform designed to help students learn programming through structured courses, lessons, and an interactive learning experience.

## 📌 About The Project

Khattab.Dev is an educational platform that provides programming courses with a clean and user-friendly interface. The platform focuses on organizing the learning journey and making technical education more accessible.

## 🚀 Features

- Modern and responsive user interface
- Course browsing and course details pages
- User authentication pages (Login & Register)
- Lesson viewing interface
- Student dashboard for tracking progress
- Profile management

## 🛠️ Technologies Used

- HTML5
- Tailwind CSS
